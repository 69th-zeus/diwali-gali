# 🪔 Diwali Gali

Light crackers on an Indian street on Diwali night, right in your browser.

**▶ Play it here: https://zeus-mtolympus.github.io/diwali-gali/**

Pick a cracker, strike the matchstick on the box, light the fuse, and hope it's not a dud. Turn your sound on, it gets loud.

## Crackers

Lakshmi bomb · Sutli bomb · Anaar · Chakri · Rocket · 100-wala ladi · Saanp goli

## Controls

| Action | Desktop | Phone |
|---|---|---|
| Step onto the street | `Enter` | Tap |
| Pick a cracker | `1` – `7` | Tap the tray |
| Light another | `Enter` | Tap |
| Mute | `M` | 🔊 button |

## Run it locally

It's one HTML file with no build step. Download `index.html` and open it in a browser.
